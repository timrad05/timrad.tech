# timrad.tech

Сайт-визитка и портфолио.

**Статус:** в разработке  
**Сайт:** [timrad.tech](https://timrad.tech)

## Стек

React, TypeScript, Vite, SCSS Modules

## Запуск

```bash
npm install
npm run dev
```

## Структура

Архитектура inspired by Feature-Sliced Design:

- `app` — точка входа и глобальные стили
- `pages` — страницы
- `widgets` — секции сайта
- `features` — интерактивная логика
- `entities` — типы и данные
- `shared` — переиспользуемый UI и утилиты
